# IND320 – Data to Decision

This repository contains my project work for **IND320 Data to Decision** at NMBU.

The project explores Norwegian reservoir data using Python, Pandas, Matplotlib and Streamlit. The first part of the project focuses on importing, exploring and visualizing the data, as well as developing an interactive Streamlit application.

## Project contents

* `IND320_part1.ipynb` – Jupyter Notebook containing the data import, exploration and visualization work.
* `main.py` – Main page of the Streamlit application.
* `pages/` – Additional pages for data exploration and visualization.
* `data/reservoirs.csv` – Reservoir dataset used by the application.
* `pyproject.toml` – Project dependencies and configuration.
* `uv.lock` – Locked dependency versions.

## Streamlit application

The interactive application provides:

* An overview of the reservoir dataset.
* A table with the imported variables and line charts showing values from the first month.
* Interactive visualization of the reservoir variables.
* Selection of individual variables or all variables together.
* Selection of a period of months for the visualization.
